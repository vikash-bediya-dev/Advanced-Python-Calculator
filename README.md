# 🚀 Advanced Scientific & Programmatic Calculator

A feature-rich, object-oriented Command Line Interface (CLI) calculator built in Python. This project goes beyond basic arithmetic to provide advanced mathematical operations, matrix calculations, unit conversions, and persistent calculation history management.

---

## ✨ Features

- **OOP Architecture:** Clean, modular, and maintainable object-oriented code design.
- **Basic Arithmetic:** Addition, subtraction, multiplication, and division with robust zero-division error handling.
- **Scientific Mode:** Power/exponents, square roots, logarithms (with custom bases), and trigonometric functions (sin, cos, tan).
- **Matrix Operations:** Powered by NumPy to perform matrix addition, multiplication, and determinant calculations.
- **Unit Converter:** Easily convert temperatures (Celsius to Fahrenheit), lengths (Kilometers to Miles), and weights (Kilograms to Pounds).
- **History Persistence:** Automatically saves recent calculations with timestamps into a local JSON file (`calc_history.json`).

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Libraries:** 
  - `math` (Built-in)
  - `json` & `os` (Built-in)
  - `datetime` (Built-in)
  - `NumPy` (For matrix computations)
